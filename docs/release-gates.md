# 首发验收门槛

当前目标：五入口（总览、行程、预算、预订与待办、方案调整），完成创建到授权分享的完整流程。

## 必须实现
- 创建旅行、日期、同行人；按天添加地点、交通、游玩、住宿；调整顺序和展示时间线。
- 分类预算、公共均分、按房间与指定人员分摊；个人分摊合计等于费用总额。
- 购票与预约状态独立；方案活动启用、放弃和备选备注。
- 保存与重新打开；授权分享，默认隐藏个人费用和订单信息。

## 发布前实际验收（当前均未完成）
- 完整主流程连续测试至少10次，成功率100%。
- 新疆案例完整录入，金额与来源核对。
- 微信开发者工具和两台不同系统真机测试。
- 3—5名未参与开发的朋友独立完成创建、添加行程及查看分享。
- 阻断级及主流程严重问题为0。
- 隐私政策、用户协议、权限说明、账号及类目材料完成。
- 体验版测试完成后才可提交审核。

本地单元测试、模拟存储测试不能替代真机、真实共享和外部试用。未经真实鉴权验证，分享功能不得标记完成。
