# 权限与数据能力说明

| 能力 | 当前状态 | 用户提示与控制 |
| --- | --- | --- |
| 微信本机存储 | 已使用 | 用于持久化旅行；保存失败在页面显示；可清理微信存储 |
| 微信转发面板 | 云配置后使用 | 仅在创建只读授权后出现可转发按钮 |
| 云函数OpenID | 代码已提供，未部署 | 只用于创建者识别及撤销权限，不由客户端传入 |
| 云数据库 | 代码已提供，未部署 | 客户端禁止直接读写；只存脱敏视图及授权元数据 |
| 位置、通讯录、相机、相册、麦克风 | 未使用 | 当前版本不申请 |
| 微信支付、订阅消息 | 未使用 | 当前版本不申请，不自动支付或发消息 |

新增任何权限前必须补充用途说明、拒绝后的替代流程、最小必要范围和隐私保护指引。
